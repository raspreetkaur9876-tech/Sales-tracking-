# Sales Tracker Project

## About the Project
The Sales Tracker is a simple data management and visualization project created using Google Sheets. It helps organize sales records and understand sales performance through summaries and charts.

## Project Objectives
- Record daily sales data.
- Calculate total sales automatically.
- Track product quantities and prices.
- Summarize daily, weekly, and monthly sales.
- Visualize sales data using charts.

## Tools Used
- Google Sheets
- Microsoft Excel
- GitHub

## Dataset Details
The sales dataset contains the following columns:
- Date
- Product
- Category
- Quantity
- Unit Price
- Total Sales

## Key Features
- Organized sales records.
- Automatic calculation of total sales using Quantity × Unit Price.
- Daily, weekly, and monthly sales summaries.
- Sales chart for easy data visualization.
- Simple and user-friendly dashboard.

## How to Use
1. Download the Excel file from this repository.
2. Open it using Microsoft Excel or import it into Google Sheets.
3. Enter sales details in the Sales Data sheet.
4. Review the summaries and chart in the Summary sheet.

## Learning Outcomes
Through this project, I practised spreadsheet formulas, data organization, sales calculations, chart creation, and basic data visualization.
